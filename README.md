CampusConnect

CampusConnect is a Java Swing-based desktop application designed to help college students manage their academic tasks, deadlines, notes, and schedules.

 Planned Features

 Student login and registration
 Academic task management
 Deadline and priority tracking
 Timetable and notes
 Progress dashboard
 MySQL database integration

 Tech Stack

 Java
 Java Swing
 JDBC
 MySQL
 Git and GitHub
